# 维护说明

## 范围

Sonorynth 的公开开发仓库为 [CLCTY/Sonorynth](https://github.com/CLCTY/Sonorynth)。维护内容包括 Android 播放流程、歌词解析与显示、缓存及来源选择、界面和主题、测试及发布签名流程。

本文件整理仓库中的可核查记录，不承诺响应时限或未来发布计划。

## 已有证据

具体安装包、校验文件和变更说明以 [发布页](https://github.com/CLCTY/Sonorynth/releases) 为准。较新的预览开发记录位于其他分支；它们不等同于已合入 `main` 或包含在某个 APK 中。

`main` 的 `test/` 含歌词解析、缓存、配色、加密、来源解析、设置导航和界面等测试文件。文件存在不代表当前检查已通过；每次变更的验证结果应在 PR 中单独记录。

## 维护流程

- 问题按复现信息处理，反馈入口为 Issues。
- PR 应解释具体行为变化、执行过的检查和验证限制。
- 发布前按 [构建说明](BUILDING.md) 进行分析、测试、签名和 APK 构建；发布页应区分稳定版与预览版。
- 许可来源记录在 [第三方说明](../THIRD_PARTY_NOTICES.md)，新增第三方代码时同步更新。

## 使用情况

项目处于早期阶段。仓库星数和单个 Release 资产的累计下载计数可随时变化；它们不等同于月活用户、独立用户数或生产部署数量。暂无可核验的独立活跃用户统计，不宣称广泛采用。
